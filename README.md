# SuperContinuity

Turn any YouTube playlist or long video into a course you'll actually finish.

- **Sessions with breaks.** Focus/break intervals that pause the video for you, with a one-line recall prompt.
- **Exact progress.** Remembers which parts you actually watched, not just where you scrubbed to.
- **A daily limit.** Suggests stopping for the day before you burn out.
- **Notes and bookmarks** at timestamps, exportable as Markdown.
- **Streaks, XP and a finish estimate**, kept quiet.

Everything stays in your browser. No account, no API key needed.

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```
